Overview & Instructions

This assignment rewrites the three calculation problems (original questions 4–6) using the familiar built-in datasets mtcars and sleep. The code style matches the preceding labs (explicit group1 / group2 subsets, base R + psych / effectsize / car).

Your main task is to choose the correct test.

For each problem a research context is given. The code deliberately lets you run either a paired or an independent-groups analysis by setting a single logical flag. Setting the flag incorrectly produces a statistically legal but conceptually wrong analysis — exactly the kind of mistake that is easy to make when the design is not carefully considered.

  • Read the research context carefully.
  • Decide whether the observations are paired / repeated-measures or independent.
  • Set the flag (paired_flag = TRUE or FALSE) accordingly.
  • Run the chunks, then answer a–c.

You may also change the outcome variable (column name) if you want to explore. Optional assumption checks remain commented; uncomment them if you wish.

No Excel or SPSS is required. Focus on correct test selection and clear interpretation of the R output.

3. Average fuel efficiency versus a benchmark

(rewritten from original problem 6)

Research context
Is the average fuel efficiency of the cars in mtcars different from a hypothesized value of 20 mpg? Only one sample of cars is available and the population standard deviation is unknown.

You may change the variable or the null value below if you wish to explore.

# Choose the variable and the null hypothesis value
x   = mtcars$mpg    # change "mpg" if desired
mu0 = 20            # change the hypothesized mean if desired

describe(x)
   vars  n  mean   sd median trimmed  mad  min  max range skew kurtosis   se
X1    1 32 20.09 6.03   19.2    19.7 5.41 10.4 33.9  23.5 0.61    -0.37 1.07
# This problem compares one sample mean against a known constant.
# Do not attempt to turn it into a two-group (independent or paired) test.
# The correct call uses the mu argument.

tt = t.test(x, mu = mu0)
