Your data and analysis

If you correctly import your data you will see the output for a hypothetical experiment. It assesses how many novels people read each month and whether that is influenced by the kind of novel they read. It is a 2 (Genre: science fiction vs. mystery) × 3 (Month: 1, 2, 3) within-subjects design (each participant provides data in every condition). Participants started with one genre type for three months, then switched to the other type for three months. The dependent variable is the number of books read (Books).

You have been given two data files that contain the same values: - Wide format (one row per subject, six condition columns) for the omnibus repeated-measures ANOVA. - Long format (one row per observation) for descriptives and follow-up comparisons.

A) Render this mark down file and look at the omnibus output. Use it to manually calculate the effect size for each of your main effects and interactions. Pull the relevant Sum of Squares values from the omnibus table into the variables below, then use those variables to compute the partial eta-squared values. The ‘Effect Sizes’ table below the omnibus will count as your response.
